# Contributing to AI-Climate-Risk-Portfolio-Explorer

Thank you for your interest in contributing. This guide explains how to report problems, suggest changes, and submit pull requests.

## Code of conduct

This project follows the Code of Conduct. By participating, you agree to follow it. Report unacceptable behavior to carlos.mendez@sei.org.

## Ways to contribute

- Report a bug
- Suggest a feature or improvement
- Improve the documentation
- Fix an issue labeled `good first issue` or `help wanted`
- Review open pull requests

## Asking questions

Use [https://github.com/sei-latam/AI-Climate-Risk-Portfolio-Explorer/discussions](https://github.com/sei-latam/AI-Climate-Risk-Portfolio-Explorer/discussions) for questions. The issue tracker is for bugs and feature requests.

## Reporting bugs

1. Search [https://github.com/sei-latam/AI-Climate-Risk-Portfolio-Explorer/issues](https://github.com/sei-latam/AI-Climate-Risk-Portfolio-Explorer/issues) to check whether the bug is already reported.
2. If it is not, open a new issue using the bug report template.
3. Include the version, operating system, steps to reproduce, expected result, and actual result.

## Reporting security issues

Do not open a public issue for a security vulnerability. Follow the process in [SECURITY.md](SECURITY.md).

## Suggesting features

Open an issue describing the problem you want to solve, who it affects, and the change you propose. For large changes, wait for maintainer feedback before starting work.

## Making changes

1. Fork the repository and create a branch from `[main]`: `git checkout -b [type]/[short-description]`
2. Make your change in small, focused commits.
3. Add or update tests for the change.
4. Update documentation when behavior changes.
5. Add an entry under `## [Unreleased]` in for user-facing changes.
6. Run the checks below before opening a pull request.

- Link the related issue, for example `Closes #123`.
- Describe what changed and why.
- Include screenshots for visible changes.
- Keep each pull request to one logical change.
- Make sure all checks pass.
